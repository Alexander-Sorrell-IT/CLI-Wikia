# muse memory

> wiki-version: 1 | cli-version: 1.4.4 | verified: 2026-10-10
> source: observed `~/.local/share/muse/memory/` + skills roster.

Persistent Markdown memory under `memory/` (`projects/` per-project
notes); reminder skills (`memory-reminder`, `skill-reminder`,
`todo-reminder`, `goal-reminder`, `verify-reminder`, `scope-reminder`,
all `tbh-reminders` reserved ids) surface it at safe points.
Toolsets `memory_lite` / `memory_full` gate access. Memory is local-only
(part of the share dir, travels with no session export by default).
